안심파일관리 사용자 매뉴얼

파일 탐색부터 중복 정리, 개인정보 탐지, 복구방지 안심 파쇄, 휴대폰 양도 준비까지. 실제 앱 화면을 보며 기능을 익혀보세요.

화면 예시: 2026년 11월 개발 버전 · 기기 및 Android 버전에 따라 화면과 지원 범위가 달라질 수 있습니다.
목차시작하기파일 찾기와 관리스마트 저장공간 최적화복구방지 안심 파쇄 센터휴대폰 양도 준비 도우미환경설정 및 앱 정보자주 묻는 질문

시작하기

앱의 기본 구조와 저장공간 현황을 확인합니다.

홈 화면

상단에는 앱 이름과 메뉴 버튼, 저장공간 사용 현황이 표시됩니다. 폴더탐색과 복구방지안심센터로 이동하거나 이미지·동영상·문서·오디오를 종류별로 확인할 수 있습니다. 최근 파일 목록에서 원하는 파일을 선택할 수도 있습니다.

파일 찾기와 관리

파일 종류 또는 폴더를 기준으로 탐색합니다.

종류별 파일 보기

격자형·목록형 전환, 날짜순 정렬, 오름차순·내림차순 전환, 검색 및 전체 선택을 사용할 수 있습니다. 파일 오른쪽의 더보기 메뉴를 통해 개별 작업을 실행합니다.

폴더 탐색기

폴더 경로를 따라 이동하고 하위 폴더와 파일을 확인합니다. 새 폴더 생성과 폴더 삭제 기능이 제공됩니다. 삭제 전 대상 폴더와 포함된 파일을 확인하세요.

파일 더보기 메뉴

미리보기, 중요/즐겨찾기 등록, 안심보관함 이동, 공유, 폴더 이동, 이름 변경, 복구방지안심삭제, 휴지통 이동 중 필요한 작업을 선택합니다.

파일 상세 보기

미리보기와 파일명, 크기, 저장일, 경로를 확인하고 편집·휴지통·공유·파쇄 등의 작업을 실행합니다.

다른 폴더로 이동

이동할 파일과 현재 경로를 확인한 후 목적지 폴더를 선택하고 이동하기를 누릅니다. 새 폴더를 만들 수도 있습니다.

스마트 저장공간 최적화

불필요한 파일과 민감정보가 포함될 수 있는 파일을 점검합니다.

최적화 메뉴

중복파일 정리, 개인정보 정밀 탐지, 캐시 및 썸네일 정리, 휴지통 일괄 파쇄로 이동합니다. 하단에서 대용량 파일도 확인할 수 있습니다.

중복파일 관리

중복 파일을 그룹별로 확인하고 유지권장 파일을 참고하여 정리할 대상을 선택합니다. 선택 파일 수와 예상 확보 공간을 확인한 후 이동 또는 삭제합니다. 같은 내용이라도 보관 목적이 다른 파일이 있을 수 있으므로 확인 후 진행하세요.

개인정보 정밀 탐지 시작

이미지·문서·기타 파일을 대상으로 주민등록번호, 계좌번호, 주소, 전화번호, 신용카드 정보, 세무정보 등의 탐지 항목을 안내합니다. 정밀 탐지 시작을 눌러 검사합니다.

탐지 결과 관리

탐지 파일 수와 위험 항목을 확인하고 유형별 필터로 결과를 좁힙니다. 각 파일의 미리보기·저장 위치·탐지 유형을 확인한 뒤 안심보관 또는 삭제를 선택합니다. 자동 탐지는 오탐과 누락이 있을 수 있습니다.

탐지 결과 주의: 민감정보 탐지는 검토를 돕는 기능입니다. 탐지된 항목이 실제 개인정보인지 사용자가 최종 확인해야 합니다.

복구방지 안심 파쇄 센터

삭제 흔적을 줄이기 위한 기능을 안내합니다.

안심 파쇄 센터

빈 공간 덮어쓰기, 숨김 썸네일 파쇄, 휴지통 일괄 파쇄를 각각 실행할 수 있습니다.

빈 공간 덮어쓰기

이미 삭제된 파일이 남겼을 수 있는 저장공간의 잔여 데이터를 덮어쓰는 기능입니다. 실행 전 충전 상태와 여유 공간을 확인하고 다른 작업을 가급적 피하세요.

캐시·썸네일·숨김휴지통 정리

탐지된 썸네일·숨김휴지통·임시 캐시를 정리합니다. 일반 파일은 유지된다는 안내가 있으나, 실제 대상 범위는 앱 접근 권한과 Android 버전에 따라 달라질 수 있습니다.

휴지통 일괄 파쇄

휴지통에 보관된 파일의 수와 크기를 확인한 뒤 파쇄를 시작합니다. 필요한 파일은 먼저 복원하세요.

작업 진행 상태

진행률과 현재 단계를 확인합니다. 작업 중에는 앱 종료와 다른 조작을 피하는 것이 좋습니다.

작업 완료 결과

완료된 작업 유형과 처리 상태를 확인합니다. 화면의 완료 표시는 해당 작업의 실행 결과를 뜻하며 모든 저장장치에서 복구 가능성이 0이 되었음을 증명하는 것은 아닙니다.

저장장치 기술적 한계: Android의 플래시 저장장치에서는 웨어 레벨링, TRIM, 암호화, 접근 권한 등의 영향으로 논리적 덮어쓰기만으로 모든 물리적 잔여 데이터의 제거를 보장할 수 없습니다.

휴대폰 양도 준비 도우미

중고 판매 또는 타인 양도 전 데이터를 점검합니다.

전체 절차 안내

중요 데이터 백업 → 개인정보 정리 및 삭제 → 삭제되지 않는 데이터 확인 → 사용자 확인 사항 순서로 진행합니다. eSIM, SD카드, 계정 로그아웃과 공장 초기화 전 확인도 안내합니다.

삭제 대상 선택

사진·동영상·문서·오디오·숨김 캐시 등 범주별 파일 수와 용량을 확인하고 삭제할 항목을 선택합니다. 기본 선택 상태를 그대로 진행하기보다 반드시 항목별로 확인하세요.

1차 기기 잠금 인증

기기의 PIN·패턴·지문 등 OS에서 제공하는 인증으로 본인 확인을 수행합니다. 잠금 인증이 설정되지 않은 기기는 먼저 기기 보안 설정이 필요할 수 있습니다.

2차 최종 확인

삭제 예정 파일 수와 용량을 재확인하고 ‘삭제확인’을 직접 입력한 후 최종 삭제를 실행합니다. 실행 후 원상 복원이 어려울 수 있으므로 백업 여부를 다시 점검하세요.

삭제 작업 완료 및 결과 확인

선택한 파일에 대한 삭제 작업이 끝나면 삭제 파일 수와 정리된 용량을 확인합니다. 이어서 양도 전 최종 점검하기를 눌러 남은 준비 사항을 확인하세요.

이 화면은 개발 시안이며, 실제 삭제를 수행해 검증한 결과 화면이 아닙니다. 표시된 파일 수와 용량은 예시입니다.

화면 시안 · 실제 실행 결과 아님

양도 전 최종 점검

파일 정리 이후에도 Google 및 제조사 계정 삭제, USIM 분리 및 eSIM 삭제, 기기 전체 공장 초기화, 초기 화면 확인 후 전원 끄기 순서로 점검합니다. 계정과 eSIM의 처리 방법은 기기 및 통신사에 따라 다를 수 있습니다.

이 화면은 안내용 시안입니다. 공장 초기화와 계정 삭제는 해당 기기의 설정에서 사용자가 직접 진행해야 하며, 필요한 백업과 계정 정보 확인을 먼저 마쳐야 합니다.

화면 시안 · 기기별 설정 방법은 다를 수 있음
양도 전 필수 확인: 이 기능만으로 Google 계정, 앱별 서버 데이터, eSIM, SD카드, 제조사 백업, 공장 초기화 절차가 모두 처리되는 것은 아닙니다. 해당 항목을 별도로 점검하세요.

환경설정 및 앱 정보

앱 오른쪽 상단의 ≡ 메뉴에서 About과 환경설정으로 이동합니다.

앱 소개 (About)

홈 화면 오른쪽 위 ≡ 메뉴에서 About을 선택합니다. 앱의 목적과 스마트 파일 관리, 복구방지 삭제, 휴대폰 양도 준비 도우미 등 주요 기능을 살펴볼 수 있습니다.

보안 처리 과정과 기대 효과

앱 소개 화면을 아래로 스크롤하면 6단계 삭제 프로세스와 개인정보 보호, 저장공간 확보, 기기 양도 준비에 관한 설명을 확인할 수 있습니다. 각 단계는 앱에서 안내하는 처리 절차이며, 모든 저장장치의 물리적 데이터 제거를 보증하는 것은 아닙니다.

화면 테마 설정

홈 화면 오른쪽 위 ≡ 메뉴에서 환경설정을 선택합니다. 화이트 모드 또는 다크 모드 카드를 눌러 원하는 화면 테마를 선택하고 확인을 누릅니다. 테마는 화면 표시 방식만 변경하며 저장된 파일에는 영향을 주지 않습니다.

자주 묻는 질문

파일을 삭제하면 무조건 복구할 수 없나요?

아닙니다. 삭제 방식과 저장장치 상태, Android 시스템 구조에 따라 결과가 다릅니다. 앱은 복구 가능성을 낮추는 작업을 지원하지만 절대적인 복구 불가능을 보장하지 않습니다.

개인정보 탐지 결과를 그대로 믿어도 되나요?

자동 탐지에는 오탐과 누락이 있을 수 있습니다. 원본 파일을 확인한 뒤 보관 또는 삭제를 결정하세요.

휴대폰 양도 전 무엇을 더 해야 하나요?

백업, 계정 로그아웃, eSIM 및 외장 메모리 확인, 제조사 안내에 따른 공장 초기화 여부 등을 별도로 점검하세요.
